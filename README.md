# PartySlate Labs + Resources

A home for some of the tools, prototypes, and resources I've built for the PartySlate team.

Some are experiments. Some solve very specific problems. Some are just useful things we wanted to have.

### Labs

- **Signature Banner Builder** — Creates custom PartySlate email signature banners from a PartySlate profile.
- **PartySlate Pro Prototype** — A working recreation of the PartySlate Pro experience I use to test proposed product messaging and imagery in context.

### Resources

- **Photo Boards Sales Guide** — A visual guide to using Photo Boards throughout the sales process.
- **Partnership Programs** — An interactive overview of PartySlate's marketing and partnership opportunities.
